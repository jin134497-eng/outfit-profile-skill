# 多维穿搭测试 · Outfit Profile

一个中文穿搭分析 skill，通过问卷、本人照片或混合模式，把个人偏好与外观线索转成可试穿的搭配建议。

## 支持的输入与结果

| 入口 | 输入 | 适合的情况 |
|---|---|---|
| 问卷 | 场景、风格偏好、身高（可选）、穿衣限制 | 不上传照片，也能获得个性化搭配 |
| 照片 | 普通衣着照片或头像，加上必要的本人补充 | 观察衣服比例、脸部线条和画面配色 |
| 混合 | 已有答案结合可选照片 | 减少重复提问，校准不确定的维度 |

结果包括多维画像、两个可探索风格方向、配色与版型建议、三套场景搭配和两个低成本试穿对照。用户只需要单品建议时会缩短流程。

“气质”指希望表达的风格和当前造型观感。照片不用于推断性格、实际身高、健康或身份，单张照片也不会被强制归入四季色彩。分类是可调整的沟通工具，不是审美评分。

## 使用

把本仓库内容放入个人技能目录下的 `outfit-profile` 文件夹，确保结构为 `outfit-profile/SKILL.md`，然后在支持此类 skill 的环境中调用：

```text
使用 $outfit-profile，先用问卷帮我做一次穿搭测试。
```

```text
使用 $outfit-profile 分析我上传的照片。我主要用于通勤，喜欢简洁风格，只穿平底鞋。
```

```text
使用 $outfit-profile。我身高 158cm，喜欢宽松黑色，不穿裙子，想用现有衣服搭配，不追求显瘦。
```

照片模式需要宿主能够读取用户提供的图片；无法读取时会转为问卷。核心流程不需要专用 API、外部图片上传服务或执行脚本。照片与答案默认只用于当前对话，不主动保存成文件或记忆；实际数据处理仍取决于宿主平台。

## 仓库结构

- `SKILL.md`：入口、决策原则、交付与反馈流程。
- `references/`：动态问卷、照片观察边界、多维搭配方法。
- `agents/openai.yaml`：技能显示名称和默认调用语。
- `evals/scenarios.md`：维护时使用的人工行为验收案例。

## 验收

更新后检查 YAML 元数据、引用路径与占位符，再按 [行为验收案例](evals/scenarios.md) 在新对话中测试。结构校验通过不等于已经完成真实照片测试，也不证明审美判断的客观性。

仓库中的案例均为虚构文本，不包含用户照片或个人测试档案。

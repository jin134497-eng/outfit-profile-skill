# 从维度到建议

这些是可选择的视觉设计手法，不是科学诊断或身体规范。不计算未经验证的“适配率”，不以固定身高阈值、单一脸型或体型名称决定穿衣资格。

## 多轴画像

| 轴 | 描述方式 | 如何转成建议 |
|---|---|---|
| 肤色与配色 | 深浅、冷暖/中性/未知；整体对比强弱；本人喜欢的颜色 | 分别考虑颜色温度、明度、饱和度与面积，提供具体色组及对照方案 |
| 身高与衣长 | 本人身高、购买裤长问题、希望的视觉效果 | 用实际试穿位置描述衣长裤长；不虚构厘米尺寸 |
| 身体与服装比例 | 肩/腰/臀的相对关系、腰线、衣物合身体验 | 调整松量、肩线、衣摆、上下装体积；不默认遮肉或显瘦 |
| 脸部与领口 | 长宽倾向、直曲线条、发型和眼镜 | 选择呼应线条或形成对比的领口、耳饰与镜框，不写成唯一规则 |
| 风格表达 | 本人期望与当前造型分开 | 用廓形、材质、图案和配饰实现，而非以性格标签命名 |
| 日常可用性 | 场景、天气、活动、预算、洗护、露肤偏好 | 先排除不满足实际需求的方案，再讨论视觉效果 |

## 可组合风格方向

- 简洁利落：清晰肩线、适度挺括、少量颜色、结构简明的鞋包。
- 柔和浪漫：流动垂坠、弧形细节、细腻纹理，可按喜好选择浅色或深色。
- 自然松弛：留有活动余量的廓形、亲肤材质、轻松叠穿与低负担鞋履。
- 活力运动：便于活动的剪裁、功能材质、运动鞋与局部色彩对比。
- 复古文艺：年代感轮廓、织物纹理、克制图案或有故事感的配饰。
- 鲜明前卫：非常规比例、几何或不对称细节、集中视觉焦点。

这些方向可以混合，任何肤色、身高与脸型都可探索。不能因为脸部柔和就排除利落造型，或因为身高较矮就排除长裙、阔腿裤。

## 条件式建议

- 用户想增强纵向延伸感：尝试相近色上下装、减少腰腿处色块切割、比较不同裤脚位置；仍检查坐下和行走是否舒适。
- 用户想强调腰线：比较上装半塞、短外搭或可调节腰带；不自动要求紧身，不把腰线高视为必然更好。
- 用户想增加肩部结构感：比较有结构的肩线和轻量叠穿；若想更柔和则试落肩、垂坠面料，前提是实际合身。
- 用户想让脸周更有纵向线条：可对比开放式领口与纵向耳饰；希望横向展开时可试较宽领口或横向细节。保留露肤、场景与个人偏好约束。
- 冷暖未知：从本人喜欢且穿着体验好的颜色出发，给同一颜色不同明度或饱和度的替代；不把“未知”直接等同“中性肤色”。
- 想用不太喜欢的近脸颜色：可尝试移到下装、鞋包或缩小面积；不宣布这个颜色永远不适合。

## 输出校准

为避免“有分类、无决策”，每次按下面顺序处理：

1. 先列硬限制，例如不穿裙、不穿高跟、只用现有衣物；候选组合必须满足。
2. 用明确偏好选择一个主方向，另选一个用户愿意探索的方向；没有偏好时并列两种方案，不强行决定主类型。
3. 从有证据的外观维度选择 2–3 个实际设计动作，例如领口形状、上衣结束位置、鞋裤衔接或近脸颜色面积；不让低可信肤色判断覆盖明确喜好。
4. 组合成满足场景的完整穿搭，再检查活动、季节、洗护和预算限制。未提供天气时将季节替代写成条件句，不假定当地温度。
5. 用试穿反馈决定保留或修改，不把第一次分类当作固定身份。

用户明确要求常见脸型或身形分类时，可以用“偏长型”“肩部相对更宽”等描述性标签；说明它来自何种可见线条或自述，保留混合与未知。标签只作为沟通简写，不给它绑定人格、必穿款或禁穿款。

色彩对照一次只改变一个主要变量：例如同样深浅与面积下比较偏暖红和偏冷红。若无法控制拍摄曝光或没有合适衣物，应记录条件差异；用户的舒适感和喜好仍是有效反馈，不伪称肉眼能精确校准屏幕色值。

结论应采用“因为【来源中的信息】，为实现【用户目标】，可尝试【具体搭配】，通过【试穿对照】判断”。不要把整体风格都归因于一项外貌。

例：用户自述 158 cm、喜欢宽松黑色、需要步行通勤、不想显瘦。可以给短外搭配阔腿裤、宽松衬衫配直筒裤、长连衣裙配平底鞋，依据是偏好与活动需求；不能推导出禁止长裙或应穿高跟鞋。

交付前核对：每个身体或色彩结论都有来源；未知信息未被填成事实；三套方案满足用户限制；配色与廓形建议可实际试穿；既有衣物优先；没有从照片推断性格、健康或身份。
